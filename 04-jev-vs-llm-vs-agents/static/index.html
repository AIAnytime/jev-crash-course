A decision model, a language model, and an agent all answer the same four questions about the same app-store reviews. Nothing here is simulated: every row is a live call, and the clock and the bill are the real ones.

Every lane states how sure it is. Bucket those statements and ask: in the bucket where it said ninety percent, was it right ninety percent of the time? The diagonal is perfect. Below it means overconfident, which is the one that quietly breaks a threshold you wrote in code.

Run a race first. Calibration is measured from the same rows.

The language model proposes what could be done. Jev picks one and says how sure it is and how risky it is. Ordinary code decides whether that is good enough to run without a person.

All three lanes answer exactly these four questions about each review. The star rating is never shown to any of them; it is kept back as the answer key.
