The rule of thumb

If the possible answers can be written down before you see the input, it is a decision, and a decision model can make it in milliseconds. If the job has to produce new sentences, or reason through several steps, it stays with a language model. If there is one correct answer and no judgement at all, it was never an AI job to begin with.
