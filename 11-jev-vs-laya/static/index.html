The hosted one against the one you run yourself

whiteboard

Two models that do the same job: answer fixed questions about text and return numbers, never sentences. One is an API you call and pay for by the token. The other is a few hundred megabytes of weights that run on this machine for nothing. Same four questions, same reviews, same answer key.

Both engines answer the same reviews. The star rating the reviewer left is held back and used as the answer key. Jev runs with calls in flight, which is how you would use an API. Laya runs one at a time, which is what one local model does. Compare the per-call medians; the wall clocks tell you what each setup actually delivers.
